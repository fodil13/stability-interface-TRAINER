# Stability-Interface Trainer
Scientific Training Framework for Protein (or any other biomolecules) Interface Stability Prediction Using Graph Neural Networks and Molecular Dynamics

The **Stability-Interface Trainer** is a sophisticated machine learning framework specifically designed for training Graph Neural Networks (GNNs) to predict protein interface stability from molecular dynamics trajectories/simulatios. 

This trainer focus on any biomolecules-biomolecules interface (protein-protein, protein-lipid, sugar-protein, etc...), employing statistical validation and temporal splitting methods to ensure scientifically rigorous model training. In this current code version, the trajectory is split in three, and it can be more or less. 

# How to select the interface of interest? 

First, the code will ask you which interface you want it to train on, bellow are exemples of three different interfaces. Between PROA (a toxin)-GLIZ (a Gt1b molecule), PROA-PROD (synaptotagmin 1) and PROD-GLIZ. The user will see all available interfaces and select them as he wish. 
Exemple of prompt:
 COMPREHENSIVE PROTEIN SEGMENT ANALYSIS:
   1. GLIZ (303 atoms)
   2. PROA (2227 atoms)
   3. PROD (895 atoms)


 -  Which interfaces are thermodynamically important?
 -  Format: '1-2,1-3' or 'all' or 'auto'
 -  Your scientific selection: all
 -  Selected: all
 -  Comprehensive: 3 interface pairs

# Training Output & Analysis

- R² score: Coefficient of determination for regression accuracy.
- Spearman Correlation: Rank-based correlation for orfinal relationships
- Mean Absolute Error (MAE): Absolute prediction errors
- Root mean Square Error (RMSE): Emphasis on larger errors
- Within-Tolerance Accuracy: Percentage within 10%, 15%, 20% error margins.

# GNN Model Architecture 

class UltimateStabilityPredictor(nn.Module):
    - Input: Graph data from MD trajectories
    - Architecture: 3-layer GCN with batch normalization
     - GCNConv(node_dim, 128) → BatchNorm → ReLU → Dropout
     - GCNConv(128, 64) → BatchNorm → ReLU → Dropout  
     - GCNConv(64, 32) → BatchNorm → ReLU → Dropout
     - Interface-focused pooling and prediction
    
    - Special Features:
    - • Spatial interface detection using KD-trees
    - • Multi-interface feature aggregation
    - • Advanced regularization techniques
    
# Temporal Interleaving Method

- MD Trajectory: [Frame0, Frame1, Frame2, Frame3, Frame4, Frame5, ...]
- Training Split: Frames 0, 3, 6, 9... (33% of data)
- Validation Split: Frames 1, 4, 7, 10... (33% of data)  
- Test Split: Frames 2, 5, 8, 11... (33% of data)

- Benefits:
- Preserves temporal distribution
- Avoids data leakage
- Consistent across all training runs
- Biologically meaningful splits
